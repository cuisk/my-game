# 鹈鹕骑行 · Pelican Ride

一只鹈鹕骑着自行车，在沿海公路上一路向前的 3D 网页小游戏。

**在线试玩：<https://cuisk.github.io/my-game/>**

纯前端、零后端、无美术与音效素材，PC 和手机浏览器打开就能玩。Three.js 已本地化到仓库中，游戏运行期间不会发出任何网络请求；最高分保存在浏览器 `localStorage`。

## 玩法

自动前进，玩家只需左右变道。金币靠近会**自动吸附**，连吃有连击倍率；路障会扣掉一颗心，三颗用完结算。

| 机制 | 说明 |
| --- | --- |
| 加速冲刺 | 按住 `Shift` 加速，消耗能量条，松开自动回复。冲刺状态下撞上路障会**直接把它撞碎**，不掉血，每个 +25 分 |
| 跳跃 | 按 `空格` 起跳，腾空可越过路障，成功闪避 +10 分 |
| 血瓶 | 残血时出现概率更高，回 1 颗心；满血拾取则转化为 +40 分和能量 |
| 金币 | 自动磁吸拾取，连续拾取触发最高 5 倍连击加成 |
| 生命 | 共 3 颗心，普通碰撞扣 1 颗并短暂无敌 |

## 操作

| 功能 | PC | 手机 |
| --- | --- | --- |
| 左右移动 | `A` / `D`、`←` / `→`，或鼠标拖动 | 左右拖动屏幕，或按住 ‹ › |
| 加速 | `Shift` | 「加速」按钮 |
| 跳跃 | `空格` | 「跳」按钮 |
| 切换预设视角 | `C` / `V` | 「视角」按钮 |
| 自由旋转视角 | `F` 开启后左键拖动，滚轮缩放；预设视角下也可右键拖动微调 | 「自由」按钮开启后单指拖动 |
| 复位视角 | `G` | 「复位」按钮 |
| 暂停 / 继续 | `P` / `Esc` | 「暂停」按钮 |
| 重开 | 结算后按 `R` 或回车 | 「再骑一次」 |

4 档预设视角：3/4 追尾、车头第一视角、侧面跟拍、高空俯视，切换时平滑过渡；竖屏会自动回正相机并放宽视野。

## 本地运行

**方式一（最简单）**：直接双击 `standalone.html`，完全离线、零依赖，不需要任何服务器。

**方式二**：起一个静态服务后打开多文件版，方便改代码调试。

```bash
python3 -m http.server 8765
# 浏览器打开 http://localhost:8765/index.html
```

修改 `game.js` / `index.html` / `style.css` 后，重新生成单文件版：

```bash
node build-standalone.mjs
```

## 项目结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架、HUD、开始 / 结算 / 暂停面板 |
| `style.css` | HUD 与移动端布局、暖光 / 暗角 / 速度线等视觉层 |
| `game.js` | 全部游戏逻辑：场景、模型、海面 shader、玩法、输入、相机 |
| `vendor/three.module.js` | Three.js r160（本地化，避免 CDN 依赖） |
| `standalone.html` | 把 CSS、Three.js、游戏逻辑全部内联后的单文件离线版 |
| `build-standalone.mjs` | 单文件版构建脚本 |

## 实现要点

- **海面**：自定义 `ShaderMaterial`，4 层正弦叠加做顶点波，配合菲涅尔水色、波峰白沫、太阳高光碎斑与近岸浅滩，再叠加会涌向岸边的动态浪花带。
- **世界**：沿 +Z 滚动模拟前进，40m 路面分段 ×9 循环复用；金币 / 血瓶 / 障碍 / 粒子全部对象池化；海鸥、云、棕榈、护栏、路牌均程序化生成。
- **碰撞**：用「上一帧 → 当前帧」的扫掠判定，加速或低帧率时也不会漏碰撞、漏拾取；`dt` 上限避免切后台后慢动作。
- **角色**：鹈鹕（长喙、喉囊、头盔、围巾、翅膀、踩踏双腿）和自行车都由基础几何体拼装，带踩踏、转向倾斜、跳跃俯仰等联动动画。
